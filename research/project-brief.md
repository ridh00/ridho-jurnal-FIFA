## Language policy

Repository documentation is maintained in English for global portability. **Research outputs are also written in English by default**, because the default target is an international, indexed outlet. Another language — Indonesian, bilingual, or multilingual — is used when the researcher states it explicitly, or when the institution, outlet, or participants require it. Record that instruction in the table above before drafting begins; an agent does not switch the output language on its own.

Source material, interview transcripts, field notes, and documents stay in their original language regardless of the output language. Quotations are translated only in the output, with the original retained where the design or the outlet requires it.

For each major output, record:

- primary language;
- required translation(s), if any;
- terminology conventions;
- treatment of quotations in another language;
- whether translated quotations require the original text alongside the translation;
- which version is authoritative when multiple language versions exist.

Translation must not strengthen or weaken claims, remove uncertainty, alter technical meaning, or obscure attribution.
