# Preset — GRAMMS (2008) reporting checklist

Type: `reporting`. Copy to `parameters/PRM-###-reporting-gramms.md` using the [reporting checklist](../../../templates/reporting-checklist.md) form. Applies to mixed-methods studies; register the reporting standard of each strand as well.

Official source: O'Cathain, A., Murphy, E., & Nicholl, J. (2008). The quality of mixed methods studies in health services research. *Journal of Health Services Research & Policy*, 13(2), 92–98 (Good Reporting of A Mixed Methods Study). Item wording below is a short paraphrase; verify against the published list and record the version used.

Status vocabulary: `ADDRESSED` (with location) / `NOT APPLICABLE` (with a design-based reason) / `OPEN`.

| Item | Requirement (paraphrase) | Manuscript location | Status | Evidence / notes |
|---|---|---|---|---|
| 1 | Justification for using a mixed-methods approach to the research question | | OPEN | |
| 2 | Design described in terms of purpose, priority, and sequence of methods | | OPEN | |
| 3 | Each method described in terms of sampling, data collection, and analysis | | OPEN | |
| 4 | Where integration occurred, how it occurred, and who participated in it | | OPEN | |
| 5 | Any limitation of one method associated with the presence of the other | | OPEN | |
| 6 | Insights gained from mixing or integrating the methods | | OPEN | |

Items 4 and 6 are where mixed-methods manuscripts most often fail: two strands are reported side by side with no integration point and no metainference. The design matrix must already name the integration point before data collection begins. See the [mixed-methods guidance](../../../method/04-mixed-methods.md).
