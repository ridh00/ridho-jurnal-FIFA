# Preset — CONSORT for Abstracts checklist

Type: `reporting`. Copy to `parameters/PRM-###-reporting-consort-abstracts.md` using the [reporting checklist](../../../templates/reporting-checklist.md) form. Applies to the abstract of a randomized trial reported in a journal or conference abstract. Register it alongside the main [CONSORT preset](consort-2010.md), whose item 1b requires it.

Official source: Hopewell, S., Clarke, M., Moher, D., Wager, E., Middleton, P., Altman, D. G., & Schulz, K. F. (2008). CONSORT for reporting randomised trials in journal and conference abstracts. *The Lancet*, 371(9609), 281–283; carried into CONSORT 2010 as item 1b. Item wording below is a short paraphrase; verify against the published checklist and record the version used. CONSORT was updated in 2025 — record which version the outlet requires.

Status vocabulary: `ADDRESSED` (with location) / `NOT APPLICABLE` (with a design-based reason) / `OPEN`.

| Item | Section | Requirement (paraphrase) | Abstract location | Status | Evidence / notes |
|---|---|---|---|---|---|
| 1 | Title | Identify the study as a randomised trial | | OPEN | |
| 2 | Authors | Contact details for the corresponding author | | OPEN | |
| 3 | Trial design | Describe the trial design, for example parallel, cluster, non-inferiority | | OPEN | |
| 4 | Methods — participants | Eligibility criteria and the settings where data were collected | | OPEN | |
| 5 | Methods — interventions | The interventions intended for each group | | OPEN | |
| 6 | Methods — objective | The specific objective or hypothesis | | OPEN | |
| 7 | Methods — outcome | The primary outcome, clearly defined | | OPEN | |
| 8 | Methods — randomisation | How participants were allocated to interventions | | OPEN | |
| 9 | Methods — blinding | Whether participants, caregivers, and outcome assessors were blinded | | OPEN | |
| 10 | Results — numbers randomised | Number randomised to each group | | OPEN | |
| 11 | Results — recruitment | Trial status or recruitment period | | OPEN | |
| 12 | Results — numbers analysed | Number analysed in each group | | OPEN | |
| 13 | Results — outcome | For the primary outcome, a result per group and the estimated effect size with its precision | | OPEN | |
| 14 | Results — harms | Important adverse events or side effects | | OPEN | |
| 15 | Conclusions | A general interpretation of the results | | OPEN | |
| 16 | Other — trial registration | Registration number and register name | | OPEN | |
| 17 | Other — funding | Source of funding | | OPEN | |

Item 13 is the abstract's substance: a result per group **and** the effect size with its precision. An abstract reporting only that a difference was statistically significant does not satisfy it.
