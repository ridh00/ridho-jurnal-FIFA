# Preset — PRISMA 2020 for Abstracts checklist

Type: `reporting`. Copy to `parameters/PRM-###-reporting-prisma-abstracts.md` using the [reporting checklist](../../../templates/reporting-checklist.md) form. Applies to the abstract of a systematic or structured review. Register it alongside the main [PRISMA 2020 preset](prisma-2020.md).

Official source: Page, M. J., McKenzie, J. E., Bossuyt, P. M., et al. (2021). The PRISMA 2020 statement. *BMJ*, 372, n71 — PRISMA 2020 for Abstracts checklist (12 items). Item wording below is a short paraphrase; verify against the published checklist and record the version used.

Status vocabulary: `ADDRESSED` (with location) / `NOT APPLICABLE` (with a design-based reason) / `OPEN`.

| Item | Section | Requirement (paraphrase) | Abstract location | Status | Evidence / notes |
|---|---|---|---|---|---|
| 1 | Title | Identify the report as a systematic review | | OPEN | |
| 2 | Background — objectives | State the main objective or question the review addresses | | OPEN | |
| 3 | Methods — eligibility criteria | Specify the inclusion and exclusion criteria for the review | | OPEN | |
| 4 | Methods — information sources | Specify the sources searched and the date each was last searched | | OPEN | |
| 5 | Methods — risk of bias | Specify the methods used to assess risk of bias in the included studies | | OPEN | |
| 6 | Methods — synthesis of results | Specify the methods used to present and synthesise results | | OPEN | |
| 7 | Results — included studies | Give the total number of included studies and participants, and summarise their relevant characteristics | | OPEN | |
| 8 | Results — synthesis of results | Present the main results, preferably with effect estimates and confidence or credible intervals; state the direction of the effect | | OPEN | |
| 9 | Discussion — limitations of evidence | State the main limitations of the evidence included in the review | | OPEN | |
| 10 | Discussion — interpretation | Provide a general interpretation of the results and their important implications | | OPEN | |
| 11 | Other — funding | Specify the primary source of funding for the review | | OPEN | |
| 12 | Other — registration | Give the register name and the registration number | | OPEN | |

Item 9 is the one most often dropped when an abstract runs over its word limit. Cutting it is a reporting failure, not an editing choice: see the [abstract rules](../../../docs/abstract-and-title.md).
