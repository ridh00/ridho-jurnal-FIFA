# Preset — empirical literature search (Stage 3)

Type: `search`. Copy to `parameters/PRM-###-search-empirical.md`. Purpose: find what has been studied about the phenomenon, where, how, and with what result, so that a research gap can be stated from a matrix rather than from impression.

| Parameter | Default value | Justification | Source | Project value |
|---|---|---|---|---|
| Databases | Scopus; Web of Science recommended for parity with Stage 2 | two indexes reduce single-index blind spots | flow Stage 3; PRISMA-S | NOT YET FILLED |
| Quartile filter | Scopus Q1–Q3 as a **priority** order for reading, not an eligibility criterion | quartile is a journal-level metric, not article quality | reporting-standards caveats | NOT YET FILLED |
| Time window | last 5 years | recency of the empirical frontier; the window is a default, not a rule | flow Stage 3 | NOT YET FILLED |
| Canonical-work exception | works outside the window may be included with a recorded reason (foundational study, closest prior study) | the window must not hide the closest comparator | research-theory skill | NOT YET FILLED |

| Document types | empirical journal articles; theses and reports when they are the only evidence for the locus | the question decides the source type | flow, searching and access | NOT YET FILLED |
| Language | English plus the working languages of the project | coverage | project brief | NOT YET FILLED |
