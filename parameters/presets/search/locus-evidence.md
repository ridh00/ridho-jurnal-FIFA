# Preset — locus evidence search (Stage 1)

Type: `search`. Copy to `parameters/PRM-###-search-locus.md`. Purpose: establish, with dated and attributable evidence, that the phenomenon exists at the locus. This search produces evidence of a phenomenon; it does not produce a research gap.

| Parameter | Default value | Justification | Source | Project value |
|---|---|---|---|---|
| Sources | official statistics; government and agency reports; organizational documents; reputable news; sector reports | phenomenon evidence is usually grey, not scholarly | flow Stage 1 | NOT YET FILLED |
| Time window | as required by the phenomenon; record start and end | the window follows when the phenomenon became observable | flow Stage 1 | NOT YET FILLED |
| Locus definition | site, population, or setting, stated precisely | evidence must be about *this* locus | `CTX`/`PHN` statements | NOT YET FILLED |
| Keyword set | phenomenon terms + locus terms, in each working language | recall across languages | flow Stage 1 | NOT YET FILLED |
| Credibility rule | record publisher, date, and provenance for every item; prefer primary reports over news summaries of them | traceability | academic integrity rules | NOT YET FILLED |
| Storage | `literature/search-online/` with one `SRC` note per item; export or `DAT` record when a dataset is downloaded | data structure | data structure | NOT YET FILLED |
| Logging | every run in the search log with a `RUN` ID, including failed searches | never estimate counts | search log template | NOT YET FILLED |
