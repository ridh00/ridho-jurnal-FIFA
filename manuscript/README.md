# Canonical manuscript

No substantive chapters exist yet. Structure should follow the research questions, design, and institutional guidance after the project brief has been completed.

A possible initial structure is: introduction; literature/theoretical debate; methodology; findings; discussion; conclusion. This may change for article-based dissertations, conceptual studies, ethnography, archival work, or other designs.

Use Markdown as the canonical source, adopt ordered filenames after the outline is decided, and keep terminology consistent. Do not write result abstracts or empirical conclusions before results exist.

Working citations may use citation keys from `references.bib`, for example `[@citation-key]`; this syntax is only an example and is not a real reference. The citation style and export engine are not configured yet. Once configured, verify citation–bibliography consistency and inspect the rendered output.

Use the [chapter plan](../templates/chapter-plan.md) before drafting a major section.

## Language policy

Repository documentation is written in English for portability. **Research outputs are written in English by default.** Another language is used when the researcher states it explicitly, or when the institution, outlet, or participants require it; record that instruction in `research/project-brief.md` before drafting. An agent does not switch the output language on its own initiative.

With an explicit instruction, a project may produce:

- Indonesian manuscripts;
- bilingual or multilingual outputs;
- different languages for different outputs when institutionally justified.

Source material stays in its original language whatever the output language. Translate a quotation only in the output, keep the original where the design or outlet requires it, and mark every translation as one.

Within any single artifact, keep terminology and language choices deliberate and consistent. Translation must preserve the strength of claims, uncertainty, technical meaning, quotations, and attribution.
