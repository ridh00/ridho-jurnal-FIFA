# Academic review

Use the [gate-review](../templates/gate-review.md) template for quality-gate assessments, and the [revision table](../templates/revision-table.md) with the [review response](../templates/review-response.md) for a round of reviewer comments. Store actual reviews with the date and manuscript version; never fabricate supervisor or reviewer comments.

When reviewer comments arrive — from a journal, an editor, a supervisor, or an examiner — the researcher uploads them as received, and they are recorded verbatim in a revision table named `YYYY-MM-DD-revision-round-N.md` with the response letter alongside it. One Issue per round tracks the table to done. See the [revision rules](../docs/revision.md).

Distinguish self/agent review, academic human review, and institutional decisions. Prioritize findings that affect the argument, evidence, method, or contribution. Closing a review comment requires a response that addresses the substance of the criticism.
