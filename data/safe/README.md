# Safe data

Only data that has been reviewed for usage rights, re-identification risk, and versioning may be stored here — for example public statistics downloaded for the locus evidence, aggregated tables, or synthetic data clearly labeled as such. The review is recorded in the decision log and referenced from the item's `DAT` record.

Nothing has been stored yet. Raw participant data, processed participant-level data, consent records, and linkage keys are never placed here; the validator rejects `data/raw/`, `data/processed/`, `data/linkage/`, and `data/consent/` paths, and this folder is not an exception to that policy.
