# Data dictionaries

One dictionary per dataset or corpus that is analyzed, using the [data dictionary](../../templates/data-dictionary.md) template. No dictionary exists yet.

A dictionary lists every variable or field: name, label, type, unit or coding, allowed values, missing-value convention, source instrument or item, transformation applied, and the `DAT` records it describes. For qualitative corpora, it lists the units of material, their identifiers, and the anonymization applied. Analysis runs reference the dictionary version they used.
