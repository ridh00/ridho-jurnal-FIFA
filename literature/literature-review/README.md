# Literature-review track — empirical studies (Stage 3)

What has been studied about the phenomenon, where, how, and with what result — by default the last five years in Scopus (Q1–Q3 as a priority order, never as an eligibility criterion), with Web of Science recommended. One [source note](../../templates/source-note.md) per included source, named by its `SRC` ID; the [literature matrix](../../templates/literature-matrix.md) as `matrix.md`. Nothing has been collected yet.

Search parameters come from the [empirical-literature preset](../../parameters/presets/search/empirical-literature.md); screening criteria are a `screening` parameter set; every run is logged with a `RUN` ID. Outputs: the matrix, three to five `LIT` pattern statements, and research `GAP` statements in [`brain.md`](../../brain.md). Canonical works outside the window may be included with a recorded reason.
