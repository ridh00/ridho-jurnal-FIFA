# Migration: 0.1.1 → 0.2.0

## Purpose

Version 0.2.0 introduces a Creswell-first methodological decision layer under `method/`.

This is a builder-level methodology framework change. It does **not** mean an existing research project must automatically change its approved design.

## What changed

- Added the `method/` knowledge layer.
- Added explicit qualitative, quantitative, and mixed-methods selection logic.
- Added a method-selection protocol for AI agents.
- Added a practical method-chapter blueprint.
- Updated `AGENTS.md` and `research-design` so methodological recommendations begin from the research problem and questions and use Creswell & Creswell's design architecture.
- Added human approval states for methodological recommendations.

## Migration procedure for a RESEARCH project

1. Create a migration Issue.
2. Read the new `method/` layer and identify whether the current project's methodological reasoning is affected.
3. Do not retroactively rewrite an approved design merely to match the new builder.
4. If the current method/design has not yet been approved, use the new method-selection protocol before approval.
5. If an approved design materially conflicts with the new decision checks, record the conflict and reopen G4 rather than silently changing the design.
6. Add any specialist methodological sources required beyond Creswell's research-design scope.
7. Update the pinned builder version only after the migration PR is reviewed and merged.

## What should not be migrated automatically

Do not automatically change:

- research questions;
- participant/sample decisions;
- instruments;
- analysis techniques;
- collected data;
- approved ethics procedures;
- manuscript claims.

Those are research decisions and require their own evidence and authorization.

## Verification

A migration can be considered mechanically complete when:

- the new `method/` files exist;
- agent instructions point to the method layer;
- the research-design skill points to the method-selection protocol;
- the project brief pins builder version 0.2.0;
- affected methodological decisions and quality gates have been reviewed rather than silently overwritten.

Mechanical completion is not proof that the study's method is academically correct.
