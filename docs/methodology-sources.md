# Specialist Methodological Sources

Better Research is Creswell-first, not Creswell-only. Creswell & Creswell (2023) decide the *architecture* of a study — worldview, approach, design, methods. When a study moves into a technical procedure that the book introduces but does not develop, the technical decision needs a specialist authority. This register names those authorities by technique family, states when they become required, and lists the parameters a study in that family must register.

Rules of use:

1. Register a specialist source only when the study actually crosses into its family. Do not cite five methods books to look thorough.
2. Verify the edition and identifier before adding the source to `references.bib`. This register is a pointer, not a bibliography.
3. Record which parameter set (`PRM`) the source justifies. A threshold or procedure without a named source is a habit, not a parameter.
4. Never use a specialist technique to invent a design after the fact; the design comes first, from the [method layer](../method/README.md).

## When Creswell is enough

Selecting the approach, naming the design, writing the purpose statement and research questions, laying out the method chapter, and choosing the family of validation strategies. For these, cite Creswell & Creswell (2023) and stop. Adding a specialist source for a decision the book already covers is padding.

## When a source becomes a decision

The moment a specialist source sets a value — a cut-off, a number of bootstrap samples, a stopping rule — that value is registered as a parameter with the source as its justification. The method decision record lists the specialist sources required; the parameter sets show where each was used.
